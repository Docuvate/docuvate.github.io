Docuvate SDKs

Official clients for scripts and integrations. The contract and codegen follow the OpenAPI document exported from your instance.

Your instance serves the OpenAPI description at GET /v1/openapi.json, matching the interactive API reference.

After API changes in your self-hosted setup: export OpenAPI and regenerate SDKs (pnpm openapi:export, pnpm sdk:codegen).

Set up service access

Scripts and integrations use a service API key. The key is bound to a user and can carry document permissions.

  1. Set DOCUVATE_SERVICE_API_KEYS in .env as a JSON array (keyId, secret, tenantUserId, claims).
  2. Call the API at https://your-host/v1.
  3. Send the secret as Authorization: Bearer <secret> or X-Docuvate-Api-Key.

Node.js and TypeScript

Install Node.js SDK

Install @docuvate/sdk from the public Git repository:

DocuvateClient with baseUrl and apiKey (service API key). Configure keys in the Service access section on this page.

Flutter

Install Flutter SDK

Add the Git dependency in pubspec.yaml and run flutter pub get:

DocuvateClientConfig with baseUrl and apiKey for headless access.
