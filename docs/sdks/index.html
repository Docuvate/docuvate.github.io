Docuvate SDKs

Offizielle Node- und Flutter-Clients für die Headless-API /v1. Vertrag und Codegenerierung basieren auf der exportierten OpenAPI: openapi/docuvate.v1.json

Laufzeit: GET /v1/openapi.json (dieselbe Beschreibung).

Nach API-Änderungen: pnpm openapi:export, dann pnpm sdk:codegen (siehe docs/sdks.md). ( docs/sdks.md in the repository.)

Service-Zugang einrichten

Für Skripte und Integrationen legen Sie einen Service-API-Schlüssel an. Der Schlüssel ist an einen Benutzer gebunden und kann Berechtigungen für Dokumente tragen.

  1. In .env die Variable DOCUVATE_SERVICE_API_KEYS als JSON-Array setzen (keyId, secret, tenantUserId, claims).
  2. API unter https://ihr-host/v1 ansprechen.
  3. Schlüssel im Header Authorization: Bearer <secret> oder X-Docuvate-Api-Key senden.

Node / TypeScript (@docuvate/sdk)

pnpm add @docuvate/sdk

DocuvateClient mit baseUrl und apiKey (Service-API-Schlüssel). Details: docs/sdks.md und packages/sdk-node/README.md.

Flutter (docuvate)

docuvate: ^1.0.0 in pubspec.yaml (Monorepo-Pfad packages/sdk-flutter)

DocuvateClientConfig mit baseUrl und apiKey für Headless-Zugriff.
